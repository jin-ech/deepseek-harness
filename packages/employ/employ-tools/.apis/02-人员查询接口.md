# 人员查询接口

## 1. 接口概述

- **接口名称**：人员查询（人员信息列表查询）
- **功能说明**：按条件分页查询人员信息列表，支持按客户、基地、姓名、身份证、残疾信息、工作状态、合同到期、考勤等多维度筛选，并附加当月考勤指标。
- **请求方式**：`GET`
- **接口路径**：`/employ/persons`
- **代码位置**：
  - 视图：`apps/persons/views.py` → `EmployPersons.get()`
  - 数据层：`module/mysql/guohua/PersonsDbModel.py` → `get_persons_list()`
- **认证方式**：需要登录，请求头携带 `token`；角色权限通过 `system-id` 请求头解析。

## 3. 请求示例

```http

```

## 4. 响应参数

### 4.1 通用响应结构

```json
{
  "code": 0,
  "timestamp": 1712345678,
  "message": "请求成功",
  "data": {},
  "errors": {},
  "request_id": 17123456780000000

```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 成功，`1` 失败，`2` 业务异常，`500` 服务异常 |

## 6. 错误码说明

| code | message | 说明 |
| --- | --- | --- |
| 1 | 请登陆 | 未携带 `token` 请求头 |
| 1 | 签名过期，请重新登陆 | `token` 无效或已过期 |
| 1 | 考勤月份格式错误，应为YYYY-MM | `attendance_month` 格式不正确 |
| 2 | 获取数据失败 | 数据查询失败 |
