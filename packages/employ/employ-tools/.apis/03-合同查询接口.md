# 合同查询接口

## 1. 接口概述

- **接口名称**：合同查询（合同列表查询）
- **功能说明**：按条件分页查询合同列表，支持按客户、合同编号/名称、合同状态、签约状态、日期范围、部门等多维度筛选，并返回合同可用状态。
- **请求方式**：`GET`
- **接口路径**：`/contract`
- **代码位置**：
  - 视图：`apps/contract/views.py` → `Contract.get()`
  - 数据层：`module/mysql/guohua/ContractDbModel.py` → `get_contract_list()`
- **认证方式**：需要登录，请求头携带 `token`；角色权限通过 `system-id` 请求头解析。

| contract_attribute | string | 否 | - | 合同属性 |
| contract_status_id | string | 否 | - | 合同状态，多个值逗号分隔（仅保留 `1/2/3/4`） |
| payment_method | string | 否 | - | 回款方式 |
| sp_status | string | 否 | - | 审批状态 |
| is_signed | int | 否 | - | 签约状态：`0` 未签约，`1` 已签约 |
| start_date | string | 否 | - | 合同开始日期 |
| add_userid | string | 否 | - | 创建人 |
| end_date | string | 否 | - | 合同结束日期 |
| add_time_start | string | 否 | - | 合同创建开始时间 |
| add_time_end | string | 否 | - | 合同创建结束时间 |

| sign_type | int | 否 | - | 签约类型：`1` 新签，`2` 续签 |
| department_id | string | 否 | - | 部门 id |
| is_rel_opportunity | string | 否 | - | 是否关联商机：`1` 已关联，`0` 未关联 |
| is_ref_customer | string | 否 | - | `1` 是否关联查询客户 |
| is_ref_payer | string | 否 | - | `1` 是否按付款方映射查询合同 |
| start_date_left | string | 否 | - | 合同开始日期（起始） |
| end_date_left | string | 否 | - | 合同开始日期（结束） |
| start_date_right | string | 否 | - | 合同结束日期（起始） |
| end_date_right | string | 否 | - | 合同结束日期（结束） |
| is_file_return | string | 否 | - | 合同是否返还：`1` 是，`2` 否 |
| sign_file_status | string | 否 | - | 签章文件状态：`0` 未转交，`1` 已转交，`2` 已收到 |
| is_all | int | 否 | - | 查询所有（`1` 时忽略数据权限） |
| customer_contract_sn | string | 否 | - | 客户合同编号 |
| product_type | int | 否 | - | 产品类型：`1` 普通，`2` 高端，`3` 定制 |
| first_approve_date_start | string | 否 | - | 第一次审批通过时间（起） |
| first_approve_date_end | string | 否 | - | 第一次审批通过时间（止） |
| visible_userids | string | 否 | - | 穿透查询指定可见用户，多个逗号分隔 |
| department_ids | string | 否 | - | 部门 ids（递归展开含自身），多个逗号分隔，如 `98,99` |
| year_month | string | 否 | - | 合同开始年月，`YYYY-MM` 或 `YYYYMM` |

> 说明：`year_month` 会覆盖 `start_date/end_date`、`start_date_right/end_date_right`，只按合同开始时间过滤。

## 3. 请求示例

```http
GET /contract?page=1&page_size=20&contract_status_id=1,2&is_signed=1&customer_name=科技
Host: <API_HOST>:9300
token: <登录令牌>
system-id: <系统标识>
```

## 4. 响应参数

### 4.1 通用响应结构

```json
{
  "code": 0,
  "timestamp": 1712345678,
  "message": "请求成功",
  "data": {},
  "errors": {},
  "request_id": 17123456780000000
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 成功，`1` 失败，`2` 业务异常，`500` 服务异常 |
| timestamp | int | 服务器时间戳 |
| message | string | 提示信息 |
| data | object | 数据体，见 4.2 |
| errors | object | 表单校验错误（如有） |
| request_id | number | 请求追踪 ID |

### 4.2 `data` 分页结构


| 字段 | 类型 | 说明 |
| --- | --- | --- |
| count | int | 符合条件的总条数 |
| pageSize | int | 每页条数 |
| list | array | 合同列表，元素字段见 4.3 |
