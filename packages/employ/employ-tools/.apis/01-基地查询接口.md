# 基地查询接口

## 1. 接口概述

- **接口名称**：基地查询（单店列表查询）
- **功能说明**：按条件分页查询就业基地（单店）列表，返回基地基本信息及实时人员/打卡/人脸等统计指标。
- **请求方式**：`GET`
- **接口路径**：`/employ/store/list`
- **代码位置**：
  - 视图：`apps/store/views.py` → `EmployStoreList.get()`
  - 数据层：`module/mysql/guohua/EmployStoreDbModel.py` → `get_store_list_realtime()`
- **认证方式**：需要登录，请求头携带 `token`（由登录接口签发，存于 Redis）。

## 2. 请求参数（Query / Form）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| store_name | string | 否 | - | 基地/单店名称 |
| userid | string | 否 | - | 负责人 ID |
| store_type | int | 否 | - | 单店类型 |
| area_name | string | 否 | - | 地区名 |
| department_id | string | 否 | - | 部门 ID |
| is_flag | string | 否 | - | 基地类型：`0` 普通基地，`1` 示范基地，`2` 自营 |
| is_recommend | int | 否 | - | 是否推荐：`0` 否，`1` 是 |
| is_face_clock | int | 否 | - | 是否启用人脸识别打卡：`0` 否，`1` 是 |
| has_file | int | 否 | - | 是否有附件：`0` 否，`1` 是 |
| persons_status | string | 否 | `2` | 人员状态 |
| start_date | string | 否 | - | 开始日期 |
| end_date | string | 否 | - | 结束日期 |
| establish_start_date | date | 否 | - | 基地建立开始日期，格式 `YYYY-MM-DD` |
| establish_end_date | date | 否 | - | 基地建立结束日期，格式 `YYYY-MM-DD` |
| page | int | 否 | `1` | 当前页码 |
| page_size | int | 否 | `20` | 每页显示条数 |

> 说明：`department_id` 传入后会自动转换为该部门下所有负责人 `userids` 进行过滤。

## 3. 请求示例

```http
GET /employ/store/list?page=1&page_size=20&is_flag=1&area_name=上海&department_id=98
Host: <API_HOST>:9300
token: <登录令牌>
system-id: <系统标识>
```

## 4. 响应参数

### 4.1 通用响应结构

```json
{
  "code": 0,
  "timestamp": 1712345678,
  "message": "请求成功",
  "data": {},
  "errors": {},
  "request_id": 17123456780000000
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 成功，`1` 失败，`2` 业务异常，`500` 服务异常 |
| timestamp | int | 服务器时间戳 |
| message | string | 提示信息 |
| data | object | 数据体，见 4.2 |
| errors | object | 表单校验错误（如有） |
| request_id | number | 请求追踪 ID |

### 4.2 `data` 分页结构

```json
{
  "count": 123,
  "pageSize": 20,
  "list": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| count | int | 符合条件的总条数 |
| pageSize | int | 每页条数 |
| list | array | 基地列表，元素字段见 4.3 |

### 4.3 `data.list` 元素字段

**基地基础信息**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| store_id | int | 基地 ID |
| store_name | string | 基地/单店名称 |
| store_type | int | 单店类型 |
| is_flag | string | 基地类型：`0` 普通，`1` 示范，`2` 自营 |
| code | string | 地区编码 |
| area_name | string | 地区名 |
| region_name | string | 区域名 |
| township | string | 所在乡镇 |
| establish_date | string | 基地建立日期 |
| agreement_start_date | string | 协议有效期开始时间 |
| agreement_end_date | string | 协议有效期结束时间 |
| userid | string | 负责人 ID |
| name | string | 负责人姓名 |
| department_id | int | 部门 ID |
| department_name | string | 部门名称 |
| disabled_name | string | 残联联系人名称 |
| disabled_phone | string | 残联联系人电话 |
| disabled_address | string | 残联联系人地址 |
| is_face_clock | int | 是否人脸打卡：`0` 否，`1` 是 |
| is_allow_clock | int | 是否允许打卡：`0` 否，`1` 是 |
| store_operate_fee | string | 基地运营管理费用（元/年） |
| store_intro | string | 残疾人之家简介 |
| base_rating | int | 基地评级：`1` A级示范，`2` B级规范，`3` C级合格，`4` D级限制 |
| base_rating_name | string | 基地评级名称 |
| base_score | int | 基地评分（1-100） |
| is_recommend | int | 是否推荐：`0` 否，`1` 是 |
| recommend_sort | int | 推荐排序 |
| has_file | int | 是否有附件：`0` 否，`1` 是 |

**实时统计指标**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| total_num | int | 基地总人数 |
| bind_num | int | 已绑定打卡人数 |
| not_bind_num | int | 未绑定打卡人数 |
| photo_num | int | 照片数量 |
| check_num | int | 已打卡人数 |
| face_pass_num | int | 人脸核验通过人数 |
| face_pass_rate | float | 人脸核验通过率 |
| weight_num | int | 重残人数 |
| light_num | int | 轻残人数 |

**附件/照片**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| file_info | array | 基地附件列表 |
| photo_info | array | 基地照片列表 |

## 6. 错误码说明

| code | message | 说明 |
| --- | --- | --- |
| 1 | 请登陆 | 未携带 `token` 请求头 |
| 1 | 签名过期，请重新登陆 | `token` 无效或已过期 |
| 1 | 请求处理错误 | 请求参数校验未通过（`errors` 中返回详情） |
| 2 | 获取数据失败 | 数据查询失败 |
