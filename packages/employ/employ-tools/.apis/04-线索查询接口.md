# 线索查询接口

## 1. 接口概述

- **接口名称**：线索查询（CRM 客户线索列表查询）
- **功能说明**：按条件分页查询客户线索列表，支持按线索名称、客户、负责人、线索来源/级别、行业、规模、签约/转客户/退回状态、日期等多维度筛选。
- **请求方式**：`GET`
- **接口路径**：`/employ/customer/opt/clue`
- **代码位置**：
  - 视图：`apps/customer/views.py` → `EmployCustomerOptClue.get()`
  - 数据层：`module/mysql/guohua/CustomerDbModel.py` → `get_customer_opt_clue_list()`
- **认证方式**：需要登录，请求头携带 `token`；角色权限通过 `system-id` 请求头解析。

## 2. 请求参数（Query / Form）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| clue_name | string | 否 | - | 线索名称（模糊匹配） |
| customer_name | string | 否 | - | 客户名（模糊匹配） |
| clue_stage | string | 否 | - | 线索阶段 |
| responsible_userid | string | 否 | - | 负责人（多个逗号分隔） |
| is_clue_share | int | 否 | - | 是否分配：`1` 是，`0` 否 |
| is_clue_change | int | 否 | - | 是否转客户：`1` 是，`0` 否 |
| prospect_source | string | 否 | - | 线索来源 |
| prospect_level | string | 否 | - | 线索级别 |
| customer_industry_id | int | 否 | - | 所属行业 id |
| customer_size | string | 否 | - | 公司规模 |
| customer_status | string | 否 | - | 客户成交状态 |
| customer_stage | string | 否 | - | 商机阶段 |
| is_contract | string | 否 | - | 是否签约：`1` 是，`0` 否 |
| is_clue_back | string | 否 | - | 是否退回：`1` 是，`0` 否 |
| is_opportunity | string | 否 | - | 是否生成商机：`1` 是，`0` 否 |
| start_date | string | 否 | - | 开始日期（按创建时间过滤） |
| end_date | string | 否 | - | 结束日期（按创建时间过滤） |
| allocate_start_date | string | 否 | - | 分配开始日期 |
| allocate_end_date | string | 否 | - | 分配结束日期 |
| page | int | 否 | `1` | 当前页 |
| page_size | int | 否 | `20` | 每页显示条数 |
| is_department | int | 否 | - | 是否查询部门数据：`1` 是，`0` 否（非 `1` 时只查当前用户） |

## 3. 请求示例

```http
GET /employ/customer/opt/clue?page=1&page_size=20&clue_name=科技&is_clue_share=1&prospect_level=A
Host: <API_HOST>:9300
token: <登录令牌>
system-id: <系统标识>
```

## 4. 响应参数

### 4.1 通用响应结构

```json
{
  "code": 0,
  "timestamp": 1712345678,
  "message": "查询成功",
  "data": {},
  "errors": {},
  "request_id": 17123456780000000
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 成功，`1` 失败，`2` 业务异常，`500` 服务异常 |
| timestamp | int | 服务器时间戳 |
| message | string | 提示信息 |
| data | object | 数据体，见 4.2 |
| errors | object | 表单校验错误（如有） |
| request_id | number | 请求追踪 ID |

### 4.2 `data` 分页结构

```json
{
  "count": 30,
  "pageSize": 20,
  "list": []
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| count | int | 符合条件的总条数 |
| pageSize | int | 每页条数 |
| list | array | 线索列表，元素字段见 4.3 |
